# HRMobileRepo — Mobile R1.4.7

نسخة الهاتف الحالية مرتبطة بنظام HRSystem وتعتمد بيانات GitHub المنشورة من Windows.

## أحدث تحسينات الواجهة
- كروت إحصائيات أصغر وأكثر تناسقًا.
- أسماء الموظفين في القائمة أخف وأوضح.
- بطاقة الموظف أصبحت موزعة على أقسام عملية بدون ملخص مزدحم.
- أيقونات تفاصيل الموظف بتوهج ذهبي هادئ.
- الخطوط المضمنة والتحديث التلقائي والكاش بقيت كما هي.

VERIFY_HR_FONTS.cmd
