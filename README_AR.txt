# HRMobileRepo — Mobile R1.3.1 Clean Focused UX

هذه النسخة تعيد ترتيب واجهة الهاتف بأسلوب أبسط وأكثر تركيزًا.

## القرار المعتمد
- بطاقة الموظف في القائمة تعرض فقط: الاسم، التسلسل، رقم الاضبارة.
- الرقم الوظيفي، الهوية، الشعبة، العنوان الوظيفي، الملاحظات وبقية الحقول تظهر داخل صفحة تفاصيل الموظف.
- البحث الشامل وبنية التحديث التلقائي والكاش من R1.2.2 بقيت كما هي.
- لم يتم تغيير بيانات الموظفين أو مسار Windows -> GitHub -> Mobile.

## التطبيق
انسخ ملفات UPDATE ONLY فوق C:\HRMobileRepo ثم شغل VERIFY_MOBILE_R1.cmd وبعدها ارفع التغيير إلى GitHub.
