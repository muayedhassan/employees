# سجل الموظفين - تطبيق الهاتف

الإصدار الحالي: Mobile R1.2 - Search and Profile UX.

مصدر البيانات: HRSystem / SQL Server عبر GitHub.

## الاستخدام اليومي

1. افتح التطبيق.
2. استخدم البحث الشامل للبحث بالاسم، اسم الأم، الرقم الوظيفي، رقم الاضبارة، رقم الهوية، الشعبة أو الاختصاص.
3. اضغط على بطاقة الموظف لفتح صفحة التفاصيل.
4. استخدم تبويبات التفاصيل: ملخص، الوظيفة، الهوية، الملاحظات، التغييرات.

## التحقق

شغل الأمر التالي من جذر المستودع:

```bat
VERIFY_MOBILE_R1.cmd
```

## ملاحظة

تحديث بيانات الموظفين يبقى من برنامج HRSystem داخل Windows. هذا الإصدار يطور واجهة البحث والتفاصيل فقط.
