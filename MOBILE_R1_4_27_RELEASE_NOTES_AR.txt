# Mobile R1.4.27 — PDF Vector No Canvas

إصلاح جذري لمشكلة بطاقة الموظف PDF على Android WebView بعد ثبوت أن التقاط DOM/Canvas غير مدعوم بصورة موثوقة على الجهاز.

- زر «معاينة البطاقة» يبقى للعرض فقط كما هو.
- زر «تحميل البطاقة» لم يعد يستخدم html2canvas أو تصوير الشاشة نهائيًا.
- يتم إنشاء صفحة PDF مباشرة من بيانات الموظف باستخدام jsPDF وأشكال ونصوص Vector.
- تضمين خطوط المشروع داخل ملف PDF وقت الإنشاء: Zain للنص العربي، SF Sultan للعناوين، وStencil للأرقام والتواريخ.
- الحفاظ على تصميم مؤسسي كحلي/فيروزي/ذهبي وصفحة A4 واحدة.
- استخدام مسار Median/Android الحالي للحفظ المباشر داخل مجلد Downloads.
- تحديث رسالة نجاح التنزيل لتطابق إعداد System downloads folder الحالي.
- لا تغيير على R1.4.25 Reports Studio أو مركز التحديثات أو بيانات الموظفين أو Windows Master Bridge.
