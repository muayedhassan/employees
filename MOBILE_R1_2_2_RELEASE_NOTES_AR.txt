Mobile R1.2.2 — Auto Update & Cache Control

- تحديث تلقائي لكاش واجهة الهاتف عند صدور إصدار واجهة جديد.
- جلب بيانات HRSystem من GitHub مع no-store وزمن فحص دوري لتقليل بقاء البيانات القديمة.
- إضافة زر داخل مركز حالة النظام: تحديث التطبيق والبيانات.
- تنظيف كاش واجهة التطبيق القديم تلقائيًا عند تبدل إصدار Service Worker.
- تحسين التعامل مع Service Worker: skipWaiting و clients.claim و updateViaCache=none.
- لا تغيير على بيانات الموظفين ولا على مسار Windows → GitHub → الهاتف.

ملاحظة: قد يحتاج الجهاز فتح التطبيق مرة واحدة بعد نشر هذا الإصدار حتى يستلم آلية التحديث التلقائي الجديدة، وبعدها تقل الحاجة لمسح الكاش يدويًا.
