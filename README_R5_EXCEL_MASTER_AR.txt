سجل الموظفين – R5 EXCEL MASTER
================================

الفكرة الأساسية
---------------
أصبح ملف Excel هو المصدر الرسمي الوحيد لبيانات الموظفين الدائميين.
الرقم الوظيفي هو المعرّف الثابت للموظف.
التطبيق المنشور على GitHub Pages للعرض والبحث والطباعة والبطاقات، ولا يقوم بتعديل بيانات الموظفين محلياً.

آلية التحديث
------------
1) عدّل الملف: data-source/employees.xlsx
2) ارفع الملف الجديد إلى GitHub بنفس الاسم والمسار.
3) GitHub Action يفحص Excel تلقائياً.
4) إذا كان الفحص سليماً، يولّد:
   - data/employees.json
   - data/fallback-data.js
   - data/version.json
   - data/change-summary.json
   - data/validation-report.json
5) يتم Commit تلقائي للبيانات الناتجة.
6) الهواتف تكتشف DATA VERSION الجديدة وتحمّلها.

الحماية من الأخطاء
------------------
يوقف GitHub Action النشر إذا وجد:
- عموداً إلزامياً مفقوداً.
- اسماً فارغاً.
- رقم اضبارة غير صحيح.
- رقم اضبارة مكرراً بين الدائميين.
- رقماً وظيفياً مكرراً.
- تغييراً في الرقم الوظيفي لموظف منشور سابقاً على نفس رقم الاضبارة.

ملاحظات لا توقف النشر
----------------------
الموظفون الذين لا يتوفر لهم رقم وظيفي يحصلون على معرف مؤقت ويظهرون كتحذير.
إذا اختفى موظف منشور سابقاً من Excel، لا يحذف تلقائياً؛ يبقى في البيانات بحالة "يحتاج مراجعة Excel" ويظهر ضمن عداد المراجعة.

التعديل داخل التطبيق
--------------------
تم إيقاف الإضافة والتعديل والحذف المحلي للموظفين في R5 لمنع التعارض مع Excel.
البيانات الرسمية تعدّل في Excel فقط.

الإصدارات
---------
إصدار البرنامج: R5-EXCEL-MASTER
إصدار البيانات: مستقل ويبدأ بصيغة DATA-YYYY.MM.DD-HHMMSS

تنبيه أمني
----------
إذا كان GitHub Pages / المستودع عاماً فإن ملفات JSON المنشورة يمكن الوصول إليها مباشرة، حتى لو كانت بعض الحقول غير ظاهرة في واجهة البرنامج.
البيانات الحالية تتضمن حقولاً شخصية مثل رقم الهوية والراتب وتاريخ الميلاد؛ لذلك يجب اعتبار ذلك عند تحديد خصوصية المشروع والبيانات المسموح بنشرها.
