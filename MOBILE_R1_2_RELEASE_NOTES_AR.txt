Mobile R1.2 - Search and Profile UX

هذا الإصدار يحسن البحث وصفحة تفاصيل الموظف داخل تطبيق الهاتف فقط.

أهم التغييرات:
- البحث الشامل أصبح الوضع الافتراضي: الاسم، اسم الأم، الرقم الوظيفي، رقم الاضبارة، رقم الهوية، الشعبة، العنوان الوظيفي، الاختصاص والملاحظات.
- نتائج البحث تعرض سبب المطابقة ومعلومات مختصرة عن الموظف.
- بطاقات الموظفين أصبحت أوضح وتعرض رقم الهوية والشعبة والرقم الوظيفي بصورة مرتبة.
- صفحة تفاصيل الموظف أصبحت أكثر احترافية مع بطاقة تعريف علوية وتبويبات منظمة.
- تحسين تبويب التغييرات وعرض القيم السابقة والحالية.

لم يتم تغيير بيانات الموظفين نفسها، ولم يتغير مسار Windows -> GitHub -> الهاتف.
