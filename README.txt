نظام سجل الموظفين - النسخة 2
================================

ما تم تنفيذه في هذه النسخة
--------------------------
1) فصل البيانات عن index.html.
2) اعتماد الرقم الوظيفي كمعرف ثابت للموظف الدائمي.
3) الموظفون الذين لا يتوفر لهم رقم وظيفي يحصلون على معرف TEMP-PERM مؤقت فقط.
4) الحفاظ على موظفي العقود الحاليين (197) بمعرفات مؤقتة CONTRACT.
5) تحديث مركزي عبر:
   data/version.json
   data/employees.json
6) حفظ آخر نسخة مركزية على الجهاز للعمل عند انقطاع الإنترنت.
7) إصلاح التعديل: لا يتم حذف الموظف حسب رقم الاضبارة، بل تعديل نفس السجل حسب المعرّف الثابت.
8) منع تكرار رقم الاضبارة داخل نفس الفئة عند الإضافة والتعديل.
9) زر في رأس التطبيق للتحقق من تحديث البيانات.
10) Service Worker و manifest لتقوية عمل التطبيق على الموبايل.
11) GitHub Action لتحويل ملف Excel تلقائياً إلى JSON عند تحديث:
    data-source/employees.xlsx

طريقة التحديث المستقبلية على GitHub
-----------------------------------
- استبدل data-source/employees.xlsx بالنسخة الجديدة.
- ارفع التغيير إلى GitHub.
- GitHub Action سيولد ملفات data تلقائياً ويزيد رقم الإصدار.
- الموبايلات تفحص data/version.json وتقرأ النسخة الجديدة.

ملاحظة مهمة
-----------
التعديلات التي تنفذ من شاشة الإدارة داخل الهاتف تحفظ محلياً على ذلك الجهاز.
إذا وصل إصدار مركزي جديد من GitHub، يتم اعتماد الإصدار المركزي وأرشفة
اللقطة المحلية القديمة بدلاً من دمجها بصمت. في مرحلة لاحقة يمكن بناء
نظام مزامنة تعديلات الإدارة مع قاعدة مركزية.
