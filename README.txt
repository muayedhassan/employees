نظام سجل الموظفين - إصدار الحماية R3
=====================================

الحالة الحالية
--------------
- الموظفون الدائمون: 855
- موظفو العقود: 197
- الإجمالي: 1052
- الرقم الوظيفي هو المعرّف الثابت للموظف الدائمي.
- رقم الاضبارة قابل للتعديل ولا يستخدم كمعرّف داخلي.

ما تم تنفيذه حتى الآن
---------------------
1) فصل بيانات الموظفين عن index.html مع نسخة احتياطية مضمّنة للعمل عند فتح الملف محلياً.
2) تحديث مركزي عبر GitHub باستخدام data/version.json و data/employees.json.
3) دعم العمل دون إنترنت باستخدام آخر نسخة محفوظة على الجهاز.
4) إصلاح التعديل بحيث يتم تحديث الموظف بواسطة المعرّف الثابت، وليس بالحذف حسب رقم الاضبارة.
5) منع تكرار رقم الاضبارة داخل نفس الفئة.
6) عرض الملف التفصيلي الكامل للموظف الدائمي من بيانات Excel.
7) GitHub Action لتحويل data-source/employees.xlsx إلى ملفات JSON تلقائياً.

حزمة حماية البيانات الجديدة R3
------------------------------
1) سجل عمليات محلي على الجهاز باستخدام IndexedDB.
   يسجل الإضافة، التعديل، النقل إلى المحذوفات، الاستعادة والتراجع.
2) زر "التراجع عن آخر عملية" للإضافة أو التعديل أو الحذف/الاستعادة ضمن نفس إصدار البيانات المركزي.
3) سلة محذوفات: زر الحذف لم يعد يحذف الموظف مباشرة، وإنما ينقله إلى المحذوفات.
4) استعادة الموظف من سلة المحذوفات مع فحص تعارض رقم الاضبارة والرقم الوظيفي.
5) حذف نهائي من سلة المحذوفات فقط وبعد تأكيد.
6) نسخ احتياطية محلية محفوظة في IndexedDB.
7) زر لإنشاء نسخة احتياطية يدوياً من شاشة الإدارة.
8) قبل استلام إصدار بيانات جديد من GitHub يتم حفظ نسخة تلقائية من التعديلات المحلية/النسخة السابقة.
9) استعادة نسخة احتياطية مع إنشاء نسخة من الوضع الحالي أولاً للحماية.
10) الاحتفاظ بحد أقصى 8 نسخ احتياطية محلية لتجنب تضخم مساحة التخزين.
11) إصدار Service Worker جديد R3-SAFETY لمنع بقاء الهواتف على الكاش القديم.

ملاحظة مهمة عن التعديلات من الهاتف
---------------------------------
التعديلات التي تنفذ داخل شاشة الإدارة تحفظ على الجهاز نفسه، ولا ترفع تلقائياً إلى GitHub.
إذا وصل إصدار مركزي جديد من Excel/GitHub، فإن النظام يحفظ نسخة احتياطية من التعديلات المحلية السابقة ثم يعتمد البيانات المركزية الجديدة.
في مرحلة لاحقة يمكن ربط البرنامج بقاعدة بيانات مركزية إذا أردنا مزامنة تعديلات الهواتف بين جميع الأجهزة فورياً.

تحديث بيانات Excel مستقبلاً
---------------------------
إذا كان التغيير خاصاً بمعلومات الموظفين فقط:
1) استبدل الملف data-source/employees.xlsx بالنسخة الجديدة.
2) اعمل Commit على GitHub.
3) GitHub Action يولد تلقائياً:
   data/employees.json
   data/fallback-data.js
   data/version.json
4) الموبايلات تكتشف رقم الإصدار الجديد وتحمل البيانات.

إذا كان التغيير تطويراً في البرنامج نفسه
----------------------------------------
ارفع الملفات الجديدة التي تم تعديلها، وبالأخص:
- index.html
- service-worker.js
مع بقية الملفات التي تغيرت في الحزمة.
لا تحذف المستودع ولا سجل Commits ولا تغير رابط GitHub Pages.

راجع ملف DEPLOY_GUIDE_AR.txt لخطوات الرفع الآمن بالتفصيل.
