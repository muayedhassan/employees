# Mobile R1.4.24 — Reports Studio Redesign

تطوير شامل لقسم التقارير فوق R1.4.23 المستقرة، دون تغيير البيانات أو Windows Master Bridge.

- إعادة بناء واجهة «استوديو التقارير» بتصميم احترافي متجاوب للهاتف.
- قوالب واضحة للتقرير: النتائج الحالية، جميع الموظفين، حسب الشعبة، حسب الاختصاص، المعدلون، الجدد، النواقص، والمراجعة.
- لوحة مؤشرات فورية لعدد السجلات والأعمدة واكتمال البيانات وآخر تحديث.
- تخصيص منظم لعنوان التقرير والنطاق والحقول الحساسة والأعمدة.
- اختيارات سريعة للأعمدة: أساسي، وظيفي، كامل، ومسح.
- معاينة رسمية داخل التطبيق مع رأس مؤسسي، رقم مرجعي، مؤشرات، جدول منظم، وتوقيعات.
- إضافة «Excel منسق» يحفظ رأس التقرير وبيانات الإصدار والألوان والجداول بدل CSV الخام فقط.
- إبقاء CSV كخيار خفيف، وإعادة تصميم طباعة/PDF بقالب A4 رسمي يستخدم خطوط المشروع: Ya Modern Pro للعناوين، ZAIN للنص، وStencil للأرقام.
- اتجاه RTL كامل، ألوان إدارية كحلي/أزرق/ذهبي، رأس جدول متكرر عند الطباعة، صفوف متناوبة، وخانة الختم والتدقيق والمصادقة.
- اختيار تلقائي لاتجاه A4: عمودي للتقارير القليلة الأعمدة وأفقي عند كثرة الأعمدة.

لا تعديل على data/ أو Excel Master أو مركز التحديثات أو الإدارة أو مسار Windows → GitHub.
