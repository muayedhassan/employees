# خطوط تطبيق الهاتف - Mobile R1.4.3

لا تحتوي هذه الحزمة ملفات الخطوط نفسها. شغل:

INSTALL_HR_FONTS.cmd C:\HR_Fonts
VERIFY_HR_FONTS.cmd

الترتيب المعتمد:
- Ya Modern Pro Bold: العناوين العربية الرئيسية.
- ZAIN Mobile: النصوص العربية، أسماء الموظفين، البحث، التفاصيل.
- Sultan Black: لمسات عربية ثقيلة محدودة فقط.
- Stencil: الأرقام، التواريخ، الإصدارات، التسلسل، رقم الأضبارة.
- Elfeera Script: النصوص الإنجليزية والزخرفية فقط.
