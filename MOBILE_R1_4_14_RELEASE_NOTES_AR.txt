# Mobile R1.4.14 — Load Restore Hotfix

هذا الإصلاح يعالج توقف تطبيق الهاتف على الواجهة الرئيسية وبقاء جميع العدادات أصفارًا بعد Mobile R1.4.13.

## السبب الجذري
تم حقن كتلة CSS الخاصة بمركز التحديثات عدة مرات داخل سلاسل HTML JavaScript المستخدمة للطباعة والتقارير، فتحولت إلى أسطر خام داخل نص مقتبس وأدت إلى SyntaxError يوقف تنفيذ JavaScript بالكامل قبل تحميل البيانات.

## ما تم إصلاحه
- إبقاء كتلة CSS الخاصة بمركز التحديثات مرة واحدة فقط داخل <style> الرئيسي.
- إزالة النسخ المحقونة داخل JavaScript/قوالب الطباعة والتقارير.
- الحفاظ على تصميم R1.4.13: التعديلات، الجديد، النواقص، والمراجعة في أعلى المركز وبشكل تفاعلي.
- استعادة مسار التحميل: fallback المحلي ثم البيانات المركزية، ثم تحديث العدادات والقوائم.
- تحديث APP_RELEASE وService Worker cache لضمان التقاط الإصلاح على الهاتف.
- تحسين فحص الإصدار بحيث يكشف خطأ JavaScript وتكرار CSS نفسه مستقبلًا.
- لا تغيير على data/ ولا Excel ولا Windows Master Bridge.
