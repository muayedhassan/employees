# Mobile R1.0 - HRSystem Linked Release

تم تنفيذ المرحلة الأولى من تطوير نسخة الهاتف بعد استقرار الربط من Windows إلى GitHub.

## التغييرات
- تحديث اسم إصدار واجهة الهاتف من R7.1.2 القديم إلى Mobile R1.0.
- تحديث Service Worker باسم كاش جديد لإجبار WebView على أخذ الواجهة الجديدة بصورة أنظف.
- إضافة أيقونات PWA محلية 192 و512.
- تحديث manifest.webmanifest بوصف واضح وأيقونات.
- تحسين منطق عرض آخر التحديثات: فارغ -> قيمة يظهر الآن ضمن التعديلات، وتظهر القيمة السابقة بكلمة "فارغ".
- إضافة تنبيه واضح داخل مركز التحديثات عند كون البيانات الحساسة مشمولة في نسخة الهاتف.
- تنظيف الوثائق القديمة R4/R5 واستبدالها بملف README_AR واحد وملاحظات إصدار واحدة.
- إضافة فحص بسيط للنسخة عبر npm run verify:mobile.

## لم يتغير
- ملفات بيانات HRSystem نفسها لم تُعدّل يدويًا.
- عدد الموظفين بقي 1052.
- آلية القراءة من GitHub بقيت كما هي.
- العمل دون إنترنت بقي كما هو.
- تعطيل مسار Excel Master القديم داخل GitHub Actions واستبداله بفحص Mobile R1 فقط، حتى لا يتم توليد بيانات فوق بيانات HRSystem المنشورة من Windows.
