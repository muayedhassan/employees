Mobile R1.5.82 — Dashboard Cleanup + Compact Header + Professional Scroll
============================================================================

الأساس:
Mobile R1.5.81 — Unified Dashboard Scroll + Title Clarity + Admin Navigation Fix

هذا الإصدار مبني مباشرة على تجربة الهاتف الفعلية، وليس على معاينة نظرية.

التغييرات الرئيسية:

1) حذف بطاقة «لوحة الموظفين» المكررة بالكامل
- إزالة بطاقة Dashboard Hero التي كانت تعرض:
  «لوحة الموظفين / الإجمالي / الدائميون / العقود».
- الأعداد تبقى متوفرة في كروت «نطاق السجل»، لذلك لا يوجد تكرار بصري.
- الإزالة فعلية من DOM بعد كل بناء للـDashboard، وليست مجرد تغيير لون.

2) إعادة تصميم الهيدر العلوي ليكون أصغر وأجمل
- تقليل ارتفاع الهيدر ومساحاته الداخلية بصورة واضحة.
- تصغير شعار الوضع مع الحفاظ على وضوحه.
- إبقاء عنوان الشاشة بارزًا وواضحًا.
- إخفاء السطر الزائد «مديرية زراعة صلاح الدين» داخل الهيدر على الهاتف لتقليل التكرار.
- إخفاء عداد الموظفين الصغير القديم داخل الهيدر لأنه مكرر.
- تنظيم التاريخ والوقت في شريط مضغوط.
- ضغط حالة الاتصال وزر «تحديث الآن» في صف واحد.
- إخفاء نص المزامنة الطويل على الهاتف مع بقاء الحالة وزر التحديث.
- الحفاظ على الثيم الداكن/الفاتح وألوان أوضاع دائم/عقد/إدارة.

3) توحيد عناوين جميع كروت الواجهة
- كل عناوين كروت «نطاق السجل» و«الموظفون» و«المسار الوظيفي» و«النظام والأدوات»
  تستخدم نفس الحجم والوزن البصري.
- نفس مستوى وضوح «الدائميون» و«العقود».
- العنوان الطويل يسمح بسطرين عند الحاجة، بدون تصغير مبالغ أو قص.

4) Scroll واحد احترافي
- يبدأ مباشرة من «نطاق السجل» بعد حذف البطاقة المكررة.
- يشمل: نطاق السجل → الموظفون → المسار الوظيفي → النظام والأدوات → آخر كرت.
- لا يوجد Scroll داخلي منفصل داخل المجموعات.
- Native momentum scrolling للهاتف + overscroll مضبوط + smooth programmatic scrolling.
- مساحة سفلية آمنة حتى يظهر آخر كرت كاملًا فوق زر «إخفاء الواجهة» وشريط النظام.
- إعادة حساب ارتفاع منطقة التمرير عند resize/orientationchange بدون MutationObserver.

5) الاستقرار
- إصلاح R1.5.79 لأول ضغطة محفوظ بالكامل.
- إصلاح R1.5.81 للتنقل بعد «إدارة النظام» محفوظ بالكامل.
- بيانات الموظفين وIndexedDB بدون تغيير.
- خريطة التدرج بدون تغيير:
  201 سلسلة / 1011 عنوانًا مربوطًا / 305 للمراجعة / 76.8%.
- الخطوط الأصلية للتطبيق وFont Awesome فقط.
- لا commit ولا push تلقائيًا.
