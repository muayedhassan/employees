Mobile R1.5.67 — Qualification Reference Layer — Candidate
=========================================================

الهدف:
إضافة معلومات بداية التعيين بحسب المؤهل داخل واجهة التدرج بشكل احترافي ومضغوط، دون تحويل التحصيل إلى قاعدة تغير مسار الموظف.

التصميم:
- بطاقة واحدة تحت بطاقة الموظف بعنوان «المؤهل وبداية التعيين».
- التحصيل الحالي.
- البداية النظامية المرجعية للمؤهل.
- شارة «مرجع فقط».
- دليل كامل مغلق يفتح عند الحاجة.
- لون سماوي/تركوازي مستقل عن الذهبي الخاص بموقع الموظف الحالي.

المرجع:
المادة (4) من قانون رواتب موظفي الدولة والقطاع العام رقم (22) لسنة 2008 المعدل.

الصفوف المرجعية:
- بدون شهادة: العاشرة / المرتبة الأولى.
- ابتدائية: العاشرة / المرتبة الرابعة.
- متوسطة: التاسعة / المرتبة الأولى.
- إعدادية بفروعها: الثامنة / المرتبة الأولى.
- معهد سنتان بعد الإعدادية: الثامنة / المرتبة الخامسة.
- بكالوريوس اعتيادي: السابعة / المرتبة الأولى.
- دراسة جامعية أولية خمس سنوات فأكثر ضمن الحالات المشمولة قانونًا: السادسة / المرتبة الأولى.
- ماجستير أو ما يعادله: السادسة / المرتبة الثالثة.
- دكتوراه: الخامسة / المرتبة الثالثة.

ضوابط:
- «بكالوريوس» وحدها لا تحسم الاعتيادي مقابل خمس سنوات؛ يعرض الاحتمالان مرجعيًا.
- «دبلوم» وحده لا يثبت أنه معهد سنتين؛ المرجع يظهر بصورة مشروطة.
- التحصيل الحالي لا يُعتبر تلقائيًا مؤهل التعيين.
- لا تغيير على الدرجة الحالية أو العنوان أو المسار.
- لا fuzzy matching ولا تعديل لبيانات الموظف.
