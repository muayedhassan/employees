Mobile R1.5.11 — Secure Data Manual Refresh

هذا التحديث يأتي فوق R1.5.10 بعد نجاح مسار Windows → Google Sheets → الهاتف.

ما الجديد:
- إضافة زر ظاهر في شريط الاتصال باسم "تحديث الآن".
- الزر يجلب آخر تعديل منشور من برنامج Windows إلى Google Sheets فورًا.
- تحديث زر حالة النظام ليصبح "تحديث البيانات الآن" بدل عبارة GitHub القديمة.
- تجاوز نسخة الكاش عند الضغط على التحديث اليدوي، ثم حفظ النسخة الجديدة محليًا.
- لا يغير التصميم العام، ولا الحركات الإدارية، ولا الإشعارات، ولا يحتوي بيانات موظفين داخل GitHub.

طريقة الاستخدام:
بعد تعديل البيانات في برنامج Windows والضغط على "نشر آمن للهاتف"، افتح الهاتف واضغط "تحديث الآن" لجلب آخر نسخة مباشرة.
