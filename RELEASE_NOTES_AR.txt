Mobile R1.5.83 — Dashboard Home + Employee List Isolation Fix
================================================================

الأساس:
Mobile R1.5.82 — Dashboard Cleanup + Compact Header + Professional Scroll

سبب الإصدار:
بعد تجربة R1.5.82 على الهاتف ظهر أن واجهة الموظفين الأصلية بقيت على subView=list
أثناء وجود الـDashboard، لذلك ظهرت أسماء الموظفين والـPagination في الخلفية.
هذا السلوك غير صحيح؛ القائمة يجب ألا تظهر إلا بعد اختيار «القائمة».

التغييرات:

1) إرجاع كرت «القائمة»
- كرت «القائمة» يعود كأول كرت واضح داخل قسم «الموظفون».
- يظهر بعرض كامل ثم تحته «التقارير» و«آخر التحديثات».
- لم تعد R1.5.80 تخفيه عمليًا؛ R1.5.83 يفرض ظهوره ويزيل class الإخفاء عند تجهيز الـDashboard.

2) عزل الواجهة الرئيسية عن محتوى الموظفين
- عند فتح التطبيق تكون الواجهة في Dashboard Home.
- #scroll بالكامل مخفي في Dashboard Home.
- Pagination (.pg-wrap) مخفية في Dashboard Home.
- mobile chrome content bar مخفي في Dashboard Home.
- لذلك لا يمكن أن تظهر أسماء الموظفين أو الصفحات خلف كروت الواجهة.

3) فتح المحتوى فقط بعد الضغط على كرت
- الضغط على «القائمة» يفتح قائمة الموظفين فقط عند الطلب.
- الضغط على التقارير / آخر التحديثات / التدرج / العناوين / الملاحظات / الأدوات
  يفتح القسم المطلوب ويغلق الـDashboard حتى يأخذ المحتوى الشاشة.
- إصلاح R1.5.81 الخاص بالتنقل بعد «إدارة النظام» محفوظ، ومعه ينتقل العرض إلى المحتوى الصحيح.

4) الرجوع إلى الواجهة الرئيسية
- زر الواجهة العائم الموجود أصلًا يتحول أثناء فتح أي محتوى إلى «الواجهة الرئيسية».
- الضغط عليه يعيد Dashboard Home ويخفي محتوى الموظفين مرة أخرى.
- لا MutationObserver جديد.

5) الاستقرار
- تصميم R1.5.82 والهيدر المضغوط والـProfessional Scroll محفوظة.
- R1.5.79 First-Tap Navigation محفوظ.
- بيانات الموظفين وIndexedDB بدون تغيير.
- خريطة التدرج بدون تغيير:
  201 سلسلة / 1011 عنوانًا مربوطًا / 305 للمراجعة / 76.8%.
- لا commit ولا push تلقائيًا.
