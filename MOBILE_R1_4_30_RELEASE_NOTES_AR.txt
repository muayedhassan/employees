Mobile R1.4.30 — PDF Browser-Shaped Arabic

الهدف
حل مشكلة تشوه الحروف العربية داخل بطاقة الموظف PDF بصورة جذرية بعد ثبوت أن jsPDF لا يعطي نتيجة موثوقة مع تشكيل RTL والخطوط العربية المخصصة في Android WebView.

الحل الجذري
- تم إيقاف استخدام jsPDF لرسم أي نص عربي داخل بطاقة الموظف.
- يتم رسم البطاقة كاملة مباشرة بواسطة Canvas 2D ومحرك النص الخاص بالمتصفح/Android WebView نفسه، وهو المحرك الذي يعرض العربية صحيحة داخل التطبيق.
- يستخدم Canvas خط ZainMobile للنص العربي، YaModernPro للعناوين، وStencil للأرقام والتواريخ، مع fallback آمن إلى Tahoma/Arial عند تعذر خط مخصص.
- النص العربي يمر إلى Canvas بصيغته Unicode الأصلية مع direction=rtl وtextAlign=right، لذلك لا يوجد processArabic ولا Arabic Presentation Forms ولا قلب يدوي للحروف.
- بعد اكتمال الرسم، تتحول البطاقة إلى صورة PNG عالية الدقة وتوضع كصفحة A4 واحدة داخل jsPDF. jsPDF هنا لا يرسم النص نهائيًا؛ دوره فقط إنشاء حاوية PDF للصورة النهائية.
- بقي مسار Median System downloads folder والتنزيل المباشر إلى Downloads كما هو بدون تغيير.
- لا تغيير على التقارير، مركز التحديثات، البيانات، Windows Master Bridge أو تصميم معاينة البطاقة.
